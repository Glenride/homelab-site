# About — Homelab by D'Vaughn House

> Homelab is a build log by D'Vaughn House, Independent AI Orchestrator, about running AI on his own hardware.

Last updated: 2026-10-21

I'm D'Vaughn House. I build with AI for a living, and I run my own infrastructure to do it — a Mac Studio serving local models over my home network, and a 2017 iMac turned into a 24/7 homelab server.

**Homelab** is the build log. Every post is something I actually set up, with the hardware, the software, what broke, and whether it's worth copying. No cloud bill required.

The rule here is simple: *no benchmark gets published unless I ran it.* If a number is on this site, it came off one of my machines. Drafts are marked as drafts until I've verified every detail.

One email a week through **The Homelab Dispatch** — the newest builds, one benchmark, one config worth copying. [Subscribe here.](/#newsletter)
