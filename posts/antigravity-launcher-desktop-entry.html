Linux has no apps folder — getting Antigravity into the launcher

by D'Vaughn House

The goal

Antigravity was extracted and sitting on disk, but it was nowhere in the app launcher. On a Mac you drag it to Applications and you're done. Linux doesn't work like that — and I learned that the hard way, in real time.

Hardware and cost

  • 2017 27" iMac running Omarchy (Arch Linux)
  • Antigravity IDE (manually extracted tarball — Google ships it with no installer)

Software stack

  • Walker — Omarchy's app launcher (opens with Super+Space)
  • A hand-written .desktop entry — the thing Linux actually uses to know an app exists

What broke and how it was fixed

The root cause is simple once you see it: a manually extracted tarball creates no .desktop entry, and without one the launcher has no idea the app exists. There's no "apps folder" to drag things into. I asked why the app just stays wherever you extracted it instead of going somewhere proper — the answer is that Linux has no /Applications. Package installs go through pacman; a loose tarball just sits there.

My part of the comedy: when I was told to move the extracted folder with mv "SRC" ~/Apps/antigravity, I ran it literally — quotes, SRC and all. SRC was a placeholder for the real path. It was not a real folder. That one's on me, and it's the reason my setup notes now say placeholders should be unmistakable.

The recipe that actually worked:

  1. Move the app to ~/Apps/antigravity (hand-installed GUI apps live in ~/Apps/<appname> — my pick, no sudo needed)
  2. Create ~/.local/share/applications/antigravity.desktop pointing at the binary
  3. Restart Walker with omarchy-restart-walker so it picks up the new entry
  4. Add a keybind — Super+A — for one-key launching

The gotcha that cost real time: the first keybind syntax I was given — bindd = SUPER, A, ... in a .conf file — was wrong for my machine. Omarchy's Hyprland config is Lua, not .conf, and the file hyprland.conf doesn't even exist here. The correct form is o.bind("SUPER + A", ...) in ~/.config/hypr/bindings.lua. Every generic Hyprland guide on the internet gives you the wrong format for Omarchy.

Verdict

On Omarchy, installing a GUI app by hand is a three-step ritual: ~/Apps, a .desktop file, restart Walker. And whenever a generic Linux guide gives you config syntax, check whether Omarchy wants the Lua version instead — it usually does.
