"Can you trun the tilting off" — making Hyprland float like a Mac

by D'Vaughn House

The goal

Hyprland's tiling was driving me up the wall. I'd resize a window exactly where I wanted it, open one more window, and the whole layout reshuffled itself. Windows stay where I put them on a Mac. I wanted that. My exact words at the time: "can you trun the tilting off, its really annoying if i resize a window then oepn another window and that window i just reszied, resizes it self to fit the screen, when I literally don't want that to happen."

Hardware and cost

  • 2017 27" iMac running Omarchy (Arch Linux)
  • Hyprland 0.56.2

Software stack

  • Hyprland — the Wayland compositor
  • Omarchy — which configures Hyprland in Lua, not the usual .conf file

What broke and how it was fixed

First surprise: ~/.config/hypr/hyprland.conf doesn't exist on Omarchy. Generic Hyprland guides all assume it does — including the first instructions I was given, which put a windowrule = float, class:.* line in that file. That advice was written for a machine that wasn't mine. Omarchy uses Lua config files instead — ~/.config/hypr/hyprland.lua and friends.

The clue was hiding in Omarchy's own defaults at /usr/share/omarchy/default/hypr/apps/localsend.lua, which showed the window-rule API in action:

o.window("localsend", { float = true, center = true })

The fix was one line appended to ~/.config/hypr/hyprland.lua — the same rule, applied to everything:

o.window(".*", { float = true, center = true })

Then hyprctl reload, and Hyprland auto-reloads on save anyway. New windows now open centered, floating, on top — macOS-style. The tiling is gone.

Where I landed: I asked for this because the reshuffling drove me nuts — then I actually learned the keybindings, and tiling started making sense. I decided against the float-by-default rule after all. The one-liner above is real and it works, but I keep tiling on now because I've learned to drive it. If you're coming from macOS and the reshuffle annoys you, the Lua line is still the escape hatch — just know you might not need it for long.

Verdict

If you're on Omarchy and the tiling life isn't for you, you don't need to fight Hyprland's config for an afternoon. One Lua line, and it floats. Just remember: Omarchy speaks Lua, not .conf — every generic Hyprland guide on the internet will send you to a file that doesn't exist. Me? I learned the keybindings and kept tiling — turns out it was the unfamiliarity bugging me, not the layout.
